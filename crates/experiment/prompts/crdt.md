## Where things are

The task is the file TASKS.md in the shared document, which only the task setter writes. A change to the task arrives as a new version of TASKS.md in the shared document, whose last line lists the changes released so far. The library counts once it is in the hub's copy of the document: every edit to a module file counts as soon as it reaches the hub, with no other step. Others' work reaches you, and yours reaches them, only when you sync.
